# 输入数据

`sample_orders.csv` 是虚构的练习数据，不是正式考试数据。

保留原始 CSV。正式数据能否进入公开仓库，以任务规则为准。复制到本目录后，用 `--file data/文件名.csv` 明确选取，不必删除示例；多份真实候选时工具不会猜测。

支持 UTF-8（含 BOM）、GB18030/GBK、带 BOM 的 UTF-16，以及逗号、分号、制表符、竖线分隔。坏行不会被跳过，清理后重名的列会报错。

数值例子：`1,234`、`￥88.5`、`1,234 元`、`12.5%`、`(88)`。含缺失的百分比仍按百分比换算；混用百分号与无单位数字时会停止，要求统一单位。ID 保留前导零；全空列保留在画像中；无法解析的非空数值记为缺失时会在局限中说明。

日期可用 `20240131`、`202401`、`2024-01-31` 等形式。整数日历日期不按纳秒时间戳解析。Unix 时间戳和 Excel 日期序号需要先按已知单位转换；含时区的日期统一到 UTC，未带时区的日期保留其表面时间值作为 UTC 解析。

比例的总体口径必须单独确认：当每行分母不同，不能用逐行比例的简单均值代表总体比例。
