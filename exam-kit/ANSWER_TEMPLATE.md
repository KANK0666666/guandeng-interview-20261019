## 怎么证明有用

业务结论只能使用发放的数据。自己补造的示例或测试数据必须标明且不能作为结论依据。区分描述、假设与实际验证，并让每个引用数字对应复算脚本或步骤。

| 项目 | 结果与证据 |
|---|---|
| 参照方案或样本参照 | 说明为何适合比较 |
| 指标与样本量 | 给出单位和分母 |
| 绝对差值、相对差异 | 说明参照；比例给百分点差 |
| 功能验证或数据验证 | 按交付类型选择适用的验证 |
| 时间/分群复核 | 数据不足时明确未完成 |
| 成本与业务价值 | 给出可核算口径；不可测时说明缺什么 |

如果只完成观察性分析，写“发现了什么历史差异、下一步如何验证”，不要写成“上线后会提升多少”。
